One line: a one-star review written by a house cat about its human.

> One star. He opens the door, I walk out, he closes it, I walk back in. He calls this my fault. I call it his job.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python 3.13 standard library and writes the entry to `/output/entry.txt`.
